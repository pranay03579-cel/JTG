# JTG Portfolio Starter

A beginner-friendly HTML, CSS and JavaScript starter structure for recreating the JTG developer portfolio design.

## Files and folders

- `index.html` — page structure
- `style.css` — page styling
- `script.js` — JavaScript interactions (to be added phase by phase)
- `images/` — images and vector assets extracted from the supplied assignment ZIP
- `reference/` — original assignment PDF

## Run locally

1. Extract this ZIP file.
2. Open the `JTG-Portfolio-Starter` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No framework, package installation, or build command is required.
